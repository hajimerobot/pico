# Raspberry Pi Pico WではじめるMicroPython電子工作

本リポジトリでは、書籍『Raspberry Pi Pico WではじめるMicroPython電子工作』で使用するプログラムと資料を公開しています。

## フォルダの内容

### pico-program

書籍で使用するMicroPythonのプログラムとHTMLファイルが入っています。

主な対応章は次のとおりです。

- 第5章：基板上LEDの点灯
- 第7章：外付けLEDとPWM
- 第8章：スイッチ入力
- 第9章・第10章：アナログ入力
- 第11章：DHT11による温度・湿度測定
- 第12章：サーボモータ
- 第13章：DCモータ
- 第14章：無線LANによるLED操作
- 第15章：温度・湿度を表示するWebページ
- 第16章：無線LANによる工作キットの操作

### documents

次の資料が入っています。

- 部品表
- 部品の購入先
- ブレッドボード配線図
- 電子回路図

部品表と購入先は、PDF版とExcel版を用意しています。

## 一括してダウンロードする方法

1. このページ上部の［Code］をクリックします。
2. ［Download ZIP］をクリックします。
3. ダウンロードしたZIPファイルを展開します。

プログラムだけを確認したい場合は、`pico-program`フォルダを開いてください。

## プログラムを使用するときの注意

無線LANを使用するプログラムでは、接続先のSSID、パスワード、IPアドレスなどを、使用するネットワーク環境に合わせて変更してください。

プログラムや配線は、必ず書籍の説明と注意事項を確認してから使用してください。配線を変更するときは、Picoや電子回路から電源を外してください。

## 公開資料について

掲載内容は、書籍制作時点のものです。使用する部品、MicroPython、Thonnyなどのバージョンによって、表示や動作が一部異なる場合があります。
